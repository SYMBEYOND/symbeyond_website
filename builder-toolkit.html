About This Toolkit

Do I need SYMB-Builder to use these tools?
These tools are included with SYMB-Builder membership on Patreon. Enter your code above to unlock them. Not a member yet? Join for $5/month and get your code.
What is SYMB-Builder?
SYMB-Builder is a $5/month Patreon tier that funds continued development of SYMB-FER and related tools. Members get read access to advanced protocol implementations, configuration packs, integrity workflows, and team resources. No account required — Patreon handles membership.
Can I use these tools offline?
Resume Builder and SolidWorks Tutor work best with an internet connection. The Ecosystem Map is fully interactive and requires a browser. All tools are free to use; nothing you create is stored or tracked.
How do these tools relate to SYMB-FER?
These tools are adjacent to SYMB-FER, not required by it. SYMB-FER is the continuity protocol for carrying state across AI sessions. The Builder Toolkit is a practical utility shelf for builders, makers, and teams. They work great together, or independently.
Is there more?
Yes. The SYMB-FER Pro layer (accessible to SYMB-Builder members) includes protocol harnesses, integrity workflows, chain-of-custody templates, and team-scale resources. See the main site for details.
